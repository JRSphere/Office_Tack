# JRS_OfficeTrack

Office Management System built for a home-service business client (__soneone__).
Developed by JRSphere.

# About
A private, login-protected web application to manage daily jobs, 
worker commissions, payments, and financial reports.

# Tech Stack
- PHP (Backend)
- MySQL (Database)
- Tailwind CSS (Frontend)
- XAMPP (Local Server)

# Features
- Admin login system
- Job entry with auto commission calculation
- Main account balance tracker
- Worker records
- Financial reports by date/month
